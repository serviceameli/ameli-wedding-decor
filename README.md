# Амели · свадебная коллекция

Отдельная свадебная витрина с готовыми решениями, фотографиями из каталога Амели, фильтрами по зонам, избранным, корзиной и демонстрационным оформлением заявки.

22 страницы: главная, каталог, 6 категорий и 14 карточек решений. Приглушённое золото, шампанское, светлый фон и графит, кириллическое название «Амели».

**Демо:** товары, цены и составы являются заглушками. Заказы не отправляются, платежи не принимаются, наличие не проверяется. Контакты Амели ведут на действующие каналы.

## Запуск

Node.js 22.13+ (рекомендуется 24).

```sh
npm ci
npm run dev
npm run build
npm test
```

`npm run preview` показывает production-сборку. `dist` публикуется в ветку `gh-pages`; GitHub Pages использует эту ветку и корневую папку. Все URL ассетов относительные, поэтому сайт работает в подпапке репозитория.

## Основные файлы

- `app/page.tsx` — страницы, каталог, корзина и оформление.
- `app/globals.css` — адаптивная дизайн-система.
- `data/catalog.ts` — заменяемый провайдер каталога и демо-товары.
- `data/categories.ts` — шесть разделов и маршруты каталога.
- `lib/navigation.ts` — ссылки для корня и подпапки сайта.
- `scripts/build-pages.mjs` — отдельные HTML-страницы категорий и товаров.
- `lib/cart.ts` — нормализация, количества, сумма.
- `docs/INTEGRATION.md` — подключение модуля арендного движка.
- `docs/FUNNEL.md` — портреты ЦА, боли и воронка, разработанные субагентом.
- `docs/DESIGN.md`, `docs/BRIEF.md` — Refero и применение Scroll Craft.
- `docs/ASSETS.json` — исходные страницы и фото.
- `public/vendor/` — неизменённый Scroll Craft и MIT-лицензия.

Это frontend, не копия серверной части исходного сайта. Для приёма реальных заявок необходимо подключить API и утверждённые условия обработки данных.
