# Подключение к основному арендному движку

Сейчас это независимый frontend-прототип. Исходный серверный движок catalog.ameli-rental.ru не копировался, его закрытый API неизвестен. Разделы и фотографии взяты с публичного сайта с разрешения владельца. GitHub Pages не исполняет серверный код и не создаёт заказы.

## Каталог

`data/catalog.ts` содержит `Product`, `Category`, `CatalogProvider` и `catalogProvider.listProducts(signal)`. Замените реализацию провайдера на модуль основного движка. Карточки, фильтры, избранное и корзина читают один интерфейс.

Обязательные поля: стабильный id, name, category, image, price, unit, description, includes, sourceUrl, isDemo. Палитра и tag нужны только для представления. Для внешних image URL замените asset(image) на преобразователь вашего CDN; текущие изображения локальны. `isDemo` и демо-тексты нужно переключить согласованно после подключения настоящих данных. Сейчас примерные цены не синхронизируются с каталогом.

## Страницы и разделы

`data/categories.ts` управляет каталогом, боковой навигацией, фильтрами и индикатором корзины. Для нового раздела добавьте строку с уникальными id и slug; свяжите товары через category. `scripts/build-pages.mjs` создаёт самостоятельные HTML-страницы для каждой категории и каждого демо-товара. Прямые ссылки открываются и перезагружаются в GitHub Pages без клиентского обхода 404.

При замене фикстур на базу данных генератор страниц должен получать реальные идентификаторы во время сборки либо маршруты нужно передать серверному движку. Демо-публикация сама не создаёт страницы для неизвестных товаров из будущей базы. Корзина общая для всех страниц.

## Корзина и заказ

`lib/cart.ts` рассчитывает количества и предварительную сумму. В localStorage сохраняются только ID товаров, количества и избранное. Контактные данные находятся только в памяти вкладки; экспорт TXT выполняется по нажатию посетителя. Сохранённая корзина нормализуется и удаляет неизвестные ID.

Перед боевым заказом сервер должен заново рассчитать цену, наличие по дате, состав, минимальный заказ, залог, доставку, монтаж и другие услуги. Браузерная сумма не является доверенным источником. Ограничение 200 единиц в демоверсии не отражает реальный остаток.

В `app/page.tsx` шаг `review` показывает только предпросмотр. Реальную отправку следует вынести в OrderProvider/createInquiry с идемпотентностью, серверной валидацией, состояниями отправки/ошибки и подтверждением от сервера. Пока не возвращён серверный номер заявки, нельзя показывать «Отправлено» или «Забронировано».

До запуска добавьте утверждённую политику обработки данных и требуемое согласие, реальные условия аренды и договор. Не переносите демонстрационное подтверждение как юридический текст. После приёмки уберите `noindex` и обновите метаданные.

## Размещение

`npm run build` собирает статические файлы в `dist` с относительными URL. Они работают в подпапке GitHub Pages, в корне домена или на хостинге основного движка. Для встраивания можно сохранить React-витрину или перенести её компоненты/стили в шаблоны CMS.
