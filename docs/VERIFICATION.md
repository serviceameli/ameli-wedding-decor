# Проверка прототипа

Проверены 10 сентября 2026 года:

- TypeScript и production-сборка Vite; линтер авторского кода.
- Четыре теста корзины: сумма смешанного заказа, уменьшение до удаления, объединение повторных позиций, очистка устаревших и некорректных данных, предел количества.
- 22 самостоятельные страницы: главная, каталог, 6 категорий и 14 решений; генератор создаёт HTML с корректными относительными путями для GitHub Pages.
- В браузере: переход главная → каталог → столы-змейки → товар; добавление с карточки и страницы товара; общая корзина при переходах; изменение количества; сохранение после перезагрузки; избранное между страницами.
- Оформление: две позиции, 2 × 18 900 + 23 900 = 61 700 ₽; вымышленные имя/телефон и дата 12.06.2027; корректный предпросмотр с явным сообщением, что заявка не отправлена. Кнопка экспорта выполняется; сохранённый файл отдельно не инспектировался.
- Визуально: главная, каталог, категории, товар, редакционный блок, форма. Проверены размеры 1440×960, 390×844, 360×800; на 360px нет горизонтального переполнения. В видимом тексте проверенных страниц нет латинских слов. Изображения загружаются.
- Финальная палитра после уточнения владельца: приглушённое золото, шампанское, слоновая кость и графит. Яркий жёлтый заменён.
- Исправлены сырое значение сортировки, слияние предложений при скрытии переносов, мелкие карточки, потеря даты при повторном рендере формы, избыточная высота мобильного списка разделов, обрезка фотографий комплектов.

Метод: CUA в доступном встроенном браузере. Ранние ошибки во время горячего редактирования (временное отсутствие компонента и изменение типа поля) относятся к промежуточным версиям; финальный сценарий выполнен после исправлений.

Ограничения: реальное мобильное устройство и браузерный режим reduced-motion не проверялись. CSS отключает движения по системному предпочтению, сохраняя контент и действия. Скролл-анимация — дополнительное оформление; каталог и заказ от неё не зависят. Стандартный видеотест Scroll Craft заменён просмотром статической галереи и проверкой её действий в CUA: видео и WebGL не используются. Рабочая отправка заказов и наличие не подключены.

Публикация проверена: GitHub Pages сообщает built, HTTPS включён, источник gh-pages. На публичном домене открыты главная, каталог, категория столов-змеек и самостоятельная карточка «Тихий сад». Заголовки страниц, префикс /ameli-wedding-decor/, фото и финальный золотой цвет кнопки корректны.
