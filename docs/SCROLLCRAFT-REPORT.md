# Scroll Craft: результат

Бриф составлен по делегированному запросу владельца и уточнён двумя последующими требованиями: многостраничный каталог с кириллицей; золото и шампанское вместо исходного яркого жёлтого. Воронку параллельно разработал отдельный субагент, исходные фотографии и разделы собрал второй.

Выбрана грамматика галереи. Изображения подводят к выбору комплектов. Семь альтернатив и причины выбора описаны в BRIEF.md: последовательная кинематографическая сцена или принудительно закреплённые экраны мешали бы доступу к каталогу. Подпись проекта — подборка с фотографиями и индикаторами выбранных зон, общая для нескольких страниц.

Первый проект в разрешённом реестре: предыдущих строк нет, сравнивать нечего. Итоговая строка добавлена в docs/scrollcraft/FINGERPRINTS.md после публикации.

| Участок | Большой экран | Телефон |
| --- | --- | --- |
| Первый экран | Раздельные фотографии, слабое смещение слоёв | Статичная композиция, крупная кнопка |
| Разделы и товары | Обычная прокрутка, отдельные адреса страниц | Категории по две, товары по одной карточке |
| История | Небольшой параллакс фотографии, появление текста | Неподвижная фотография и текст |
| Шаги | Последовательное появление | Доступный контент без задержки действий |
| Вопросы и завершение | Нативные раскрывающиеся ответы, обычная навигация | Те же действия без закреплённых сцен |

Намеченная последовательность: интерес → облегчение → выбор → уверенность → ясность. При просмотре: интерес на первом экране; ориентация в каталоге; выбор на странице товара; спокойствие в пояснениях и ответах. Основное время и площадь отданы коллекции. После проверки увеличены тексты и мобильные карточки, список разделов на телефоне свёрнут, длинные названия сохранены читаемыми. Цвет изменён по прямому уточнению владельца.

Сгенерированных изображений, видео и платных вызовов нет. Оригинальный движок Scroll Craft сохранён без изменений. Практические требования каталога имеют приоритет над количеством анимационных приёмов; декоративное закрепление экранов не добавлялось. Полная проверка стандартным видеоскраббинг-харнессом не выполнялась: применены CUA, визуальные проверки ключевых страниц и проверки действий. Границы покрытия перечислены в VERIFICATION.md.

Публикация: https://serviceameli.github.io/ameli-wedding-decor/. Локальный запуск: npm run dev, http://127.0.0.1:5173/.
