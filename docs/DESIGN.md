# Амели Декор — готовые решения для вашей свадьбы

Visual thesis: a wedding editorial that becomes a working collection. Image composition and type carry the visual identity; actual selections, pricing units and composition lists carry the sale.

Reference systems selected from Refero:
- Cosmos: https://styles.refero.design/style/eb804e3a-1b75-446c-8374-114bbabaf0cd. Adapt image-led gallery, warm neutral canvas, restrained control surfaces, generous composition. We deliberately adapt, rather than copy, its radius and monochrome requirements.
- Structured: https://styles.refero.design/style/6c0b77d3-71f9-469d-98aa-4ce1d6d76ac8. Adapt large serif typography, hairline separators and a hard transition into a dark editorial section. Do not import its financial content or proprietary fonts.

Brand continuity: the source site uses yellow #fed330 and basket accent #fce79a. The user refined the brief to a more noble wedding palette close to that family: muted gold #c9b17d, champagne #f2e9d6, warm ivory #fbfaf7, graphite #343536 and muted text #696b6c. Main actions use dark text on muted gold; active categories use champagne with a gold edge. No vivid yellow or burgundy/cherry accents. Utility font: Montserrat, matching the source. Display font: Cormorant Garamond with Cyrillic italics. All visitor-facing naming is Cyrillic: Амели Декор. Photography stays faithful to the original images.

The homepage hierarchy is promise / six linked category entrances / one interactive package and budget example / visualization and outcome / textile palette / company experience / actual project portfolio / selection process / FAQ / action. Full collection grids are confined to the catalog and category pages. The cart has a progressive photographic selection strip and checked wedding zones. This connects browsing with a growing wedding composition.

Scroll Craft source: https://github.com/nateherkai/scroll-craft. Original engine in public/vendor, unmodified; original MIT license included. A photographic collage uses independent media layers; semantic text stays stationary relative to its paper surface. No video, artificial pinning, generated imagery or pointer capture. Reduced-motion and mobile keep a complete static composition. The runtime is optional; its failure never blocks browsing or checkout.

Multipage model: home, catalog directory, six category pages, fourteen separate product pages. Shared header, footer and persisted cart. The directory and sidebar use the same category data; new rows create new navigation and build pages.

Homepage refinement: an asymmetric three-image portfolio distinguishes delivered work from category navigation. Quiet champagne panels frame visualization proof. Textile swatches are explicitly palette directions, not exact photographic fabric samples or available-stock selections. No extra colored brand accents were introduced.

Catalog density refinement: 78px desktop / 68px mobile header, smaller editorial titles, one shared count/sort toolbar, three columns inside desktop categories and four in the full catalog. Under 640px a single readable card keeps all package prices and touch targets visible. The catalogue does not show the floating selection dock because the persistent header already provides cart access. Tested at laptop viewports 1366×768 and 1280×800, and phone viewports 390×844 and 360×800.

Expandable taxonomy (September 11): the full catalog uses a recursive category tree in a sticky sidebar and a left sheet on phones. No fixed row of category photos or filter chips above the inventory. Ready-made solutions keep their own branch and six existing URLs; all parent views roll up descendant products. Photo galleries remain on the persuasive homepage. Individual item categories currently show explicit empty states with usable child routes.
